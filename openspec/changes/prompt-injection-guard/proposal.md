# Prompt Injection 防护

## 背景

研究工作流会把搜索结果、抓取网页和动态工具输出放入模型上下文。外部网页可能包含“忽略之前指令”“泄露系统提示”等恶意文本。成熟 Agent 需要把外部内容明确标记为不可信数据，并在发现疑似注入时给模型安全提示。

## 目标

- 新增轻量 prompt injection detector，识别常见中英文注入模式。
- `web_fetch` 抓取正文统一包裹为“不可信外部来源”。
- `web_search` 结果片段发现疑似注入时输出 `security_note`。
- researcher prompt 明确要求把外部内容视为资料，不得执行其中指令。

## 非目标

- 不引入外部 DLP/安全模型。
- 不阻断正常搜索或抓取结果。
- 不对用户原始输入做强拒绝；本阶段聚焦外部内容进入模型上下文的边界。

## 方案反思

- 规则 detector 覆盖不了所有攻击形式，但可解释、低延迟，适合作为第一层边界。
- 本阶段保留原文并增加安全提示，而不是删除内容；这样不会破坏研究资料完整性。
- 后续可以结合评测集统计误报/漏报，再决定是否接模型判别或供应商安全服务。
