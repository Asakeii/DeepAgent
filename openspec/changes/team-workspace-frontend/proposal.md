# Team Workspace Frontend

## 背景

团队空间后端已经支持 `teams`、`team_members`、团队 thread 边界和团队金额预算，但前端仍停留在个人工作台。真实落地时，团队用户需要明确知道当前 run 落在哪个空间，历史会话也应按空间过滤，否则团队 thread、共享 artifact 和预算治理都很难被稳定使用。

## 变更

- 前端新增个人/团队空间切换器。
- `/api/sessions` 支持可选 `team_id` 过滤，个人空间用空 `team_id` 过滤。
- 新建团队后自动切到该团队空间。
- 新 Agent run 会携带当前 `team_id`，保证 thread 从创建时就归属正确团队。
- 前端支持读取和保存团队每日金额预算。

## 反思与边界

- 本阶段不实现完整成员管理 UI，避免在一个顶部控件里塞入过多团队管理流程。
- session 过滤放到后端，避免前端只在第一页历史里做不完整过滤。
- 团队空间选择只存 localStorage，不进入服务端 session；后端仍以请求携带的 `team_id` 和共享数据库权限为准，适合多 pod 无状态部署。
