# Product

## Register

product

## Users

deepAgent is used by people who want one focused workspace for AI-assisted research and daily self-discipline tracking. They are usually in a task flow: asking a research question, reviewing an agent plan, watching tool-backed progress, saving a report, recording a meal or workout, or checking prior sessions.

## Product Purpose

The product turns a multi-agent backend into a trustworthy interactive assistant. Success means users can understand what the agent is doing, intervene before research runs, follow sources and tool activity, recover prior sessions, and continue lightweight check-in workflows without feeling the system is opaque.

## Brand Personality

Focused, calm, capable. The interface should feel like a clear workbench for serious thinking, with enough warmth to make repeated daily use pleasant.

## Anti-references

Avoid marketing-page composition, oversized decorative heroes, generic SaaS card grids, chat UIs that hide agent state, terminal-only aesthetics, and noisy visual effects that compete with research output. Avoid making the check-in assistant feel like a gamified habit toy; the product should stay useful and adult.

## Design Principles

1. Make agent state legible: planning, searching, tool use, interruption, and reporting should be visible without overwhelming the transcript.
2. Keep the user in control: plan review, edit feedback, cancellation states, and errors should be explicit.
3. Preserve task focus: reports, citations, and history should be easy to scan and return to.
4. Favor familiar product patterns: buttons, panels, lists, tabs, and form controls should behave predictably.
5. Build for repeated use: responsive layout, keyboard ergonomics, reduced motion, and accessible contrast matter more than visual novelty.

## Accessibility & Inclusion

Target WCAG AA contrast for text and controls. Support keyboard operation for primary chat, plan review, history selection, and image attachment. Respect reduced motion. Do not rely on color alone for agent status, errors, or completion.
